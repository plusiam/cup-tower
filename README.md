# 종이컵 탑 쌓기

**경쟁을 협력으로 03** · 교사 진행용 전자칠판 도구

네 사람이 실을 한 가닥씩 잡고, 손으로 컵을 만지지 않은 채 고무줄을 벌렸다 오므리며 종이컵 탑을 쌓는 놀이입니다. 혼자 잘하는 사람이 있어도 성공할 수 없다는 것을 몸으로 느끼게 하는 활동이며, 이주배경학생의 또래 어울림 지원을 염두에 두고 만들었습니다.

👉 **[바로 사용하기](https://plusiam.github.io/cup-tower/)**

## 준비물

모둠당 — 4명 · 종이컵 20개 · 고무줄 1개 · 실 4가닥

## 화면 구성

| 화면 | 하는 일 |
|---|---|
| 미션 소개 | 규칙을 한 줄씩 열어 보여 줍니다 |
| 모둠 설정 | 모둠 수(2~12), 모둠 이름, 색·그림 배지 |
| 진행 | 연습/본 경기 모드, 타이머, 모둠별 층수와 무너짐 기록 |
| 결과 | 모둠별 순위 |
| 학급 합계 | 순위를 지우고 반 전체가 쌓은 컵을 하나의 탑으로 |

## 진행 방법

1. **연습 모드**로 컵 하나를 잡고 내려놓는 것부터 해 봅니다. 시간을 재지 않습니다.
2. **본 경기**로 바꾸고 시간을 정한 뒤 시작합니다. 기본 3분, 30초 단위로 조절합니다.
3. 탑이 한 층 올라갈 때마다 모둠 카드의 컵 그림이나 `+` 를 누릅니다.
4. 무너지면 **무너짐**을 눌러 기록하되 순위에는 반영하지 않습니다. 누구 때문인지 찾지 않기 위해서입니다.
5. 마무리는 **학급 합계**로. 모둠별 순위가 사라지고 우리 반이 함께 쌓은 컵만 남습니다.

## 언어의 문턱 낮추기

- 모둠을 **색과 그림**으로 구분해, 한글을 못 읽어도 자기 자리를 찾을 수 있게 했습니다.
- 화면 위쪽 **신호 언어** 버튼(하나 둘 셋 / 천천히 / 멈춰)을 누르면 큰 글씨로 뜹니다. 말이 서툰 아이도 모둠 안에서 쓸 수 있는 최소 어휘입니다.

## 단축키

| 키 | 기능 |
|---|---|
| `스페이스` | 미션 화면에서는 다음 규칙 / 진행 화면에서는 시작·멈춤 |
| `R` | 타이머 되돌리기 |
| `Esc` | 신호 화면 닫기 |

## 기술

단일 `index.html`. 별도 설치나 빌드가 없고, 새로고침하면 기록이 초기화됩니다.
